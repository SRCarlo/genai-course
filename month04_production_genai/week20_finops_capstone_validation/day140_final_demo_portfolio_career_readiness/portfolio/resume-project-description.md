# Resume Project

## Multi-Tenant GenAI SaaS Knowledge Assistant

**Technologies:** JavaScript, Node.js, Express.js, Next.js, React, LLM APIs, RAG, embeddings, Git, Docker.

### Project Description

Designed and developed an educational multi-tenant GenAI knowledge assistant concept that uses a Retrieval-Augmented Generation architecture to support document-based question answering.

### Key Engineering Areas

- Designed backend API architecture using Node.js and Express.js.
- Explored RAG workflows including chunking, embeddings, retrieval, and contextual generation.
- Developed tenant-aware authorization concepts.
- Built educational usage tracking and token cost estimation modules.
- Explored quota management and budget monitoring.
- Added examples for structured logging, evaluation, testing, and release validation.
- Documented deployment, security, and production readiness considerations.

# Day 101 Assignment

## Task 1 — Structured Logger

Implement info, warn and error logs with timestamp, event and requestId.

## Task 2 — Request Tracking

Generate and return X-Request-ID for every API request.

## Task 3 — Latency Monitoring

Measure retrieval, LLM and total request latency.

## Task 4 — Metrics

Track requests, errors, LLM requests and retrieval requests.

## Task 5 — AI Metrics

Track input, output, total and context tokens plus cost.

## Task 6 — Quality Monitoring

Track faithfulness, answer relevance and Recall@5.

## Task 7 — SLO

Configure P95 latency, error rate, faithfulness and Recall@5.

## Task 8 — Alerts

Alert on latency, error rate, quality degradation, retrieval degradation, cost and token spikes.

## Task 9 — Context Guard

Reject context above the configured limit.

## Task 10 — Incident Simulation

Simulate error rate > 10%, faithfulness < 90% and P95 latency > 2 seconds.

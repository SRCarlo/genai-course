# Data Governance Policy

## Classifications

| Classification | Demo AI Processing |
|---|---|
| PUBLIC | Allowed |
| INTERNAL | Allowed |
| CONFIDENTIAL | Not allowed by default |
| RESTRICTED | Not allowed |

## Data Minimization
Only send information required for the task.

## Examples
- Public documentation → PUBLIC
- Internal engineering documentation → INTERNAL
- Customer contracts → CONFIDENTIAL
- Passwords and credentials → RESTRICTED

This is an educational policy. Real organizations must define classifications and processing rules according to their own requirements.

# AI Usage Policy

## Purpose
Define acceptable use of the Day 105 production-style AI system.

## Allowed
- Approved business use cases
- Approved data classifications
- Approved models
- Approved tools
- Human review where required

## Prohibited
- Unauthorized data access
- Credential or secret submission
- Circumventing security controls
- Unauthorized tool execution
- Deliberate abuse
- Sending restricted data to the model

## Human Oversight
High-impact actions require human review.

## Security
Security controls must not be bypassed. API keys must be stored in environment variables and never committed to Git.

## Monitoring
AI usage may be monitored through appropriate audit and observability controls.

## Model Provider
This learning project uses Groq with the model `openai/gpt-oss-20b`. Provider/model approval must be reviewed before production use.

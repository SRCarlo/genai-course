# Day 66 — AI Security & Prompt Injection Defense

Advanced / Production

This project implements a defensive security layer for LLM, RAG and Agentic AI applications.

---

# Objectives

The security layer protects against:

- Direct prompt injection
- Indirect prompt injection
- Jailbreaking
- System prompt extraction
- Data leakage
- Malicious RAG documents
- Unauthorized tool calls
- Invalid tool arguments
- Excessive agent iterations
- Excessive API requests
- Secret leakage

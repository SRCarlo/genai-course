# Day 68 — CI/CD for GenAI Applications

Production-focused CI/CD example using Node.js, GitHub Actions and optional Groq AI evaluation.

Docker is intentionally excluded.

## Features

- Node.js
- Express
- Unit testing
- Integration testing
- Security regression testing
- AI evaluation
- AI quality gates
- GitHub Actions
- GitHub Secrets
- Groq API
- Nightly evaluation

## Install

```powershell
npm ci
```

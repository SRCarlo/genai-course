# HTTP Errors

## HTTP 429

HTTP 429 means Too Many Requests.

It indicates that the client has sent too many requests in a given amount of time.

A Node.js API can handle HTTP 429 responses by applying rate limiting, retry strategies, exponential backoff, and clear client communication.

## HTTP 401

HTTP 401 means Unauthorized.

It generally indicates that authentication credentials are missing or invalid.

## HTTP 403

HTTP 403 means Forbidden.

It indicates that the server understood the request but refuses to authorize it.

# Node.js

Node.js is a JavaScript runtime that allows JavaScript to run outside the browser.

## Express

Express is a web framework commonly used to build Node.js APIs.

## Error Handling

Node.js APIs should validate input and handle errors consistently.

API errors should use appropriate HTTP status codes.

## Rate Limiting

Node.js APIs can implement rate limiting to prevent clients from sending excessive requests.

When a client exceeds a configured request limit, the API can return HTTP 429 Too Many Requests.

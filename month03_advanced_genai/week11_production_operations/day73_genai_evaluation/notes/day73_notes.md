# DAY 73 — GENAI EVALUATION

## Testing vs Evaluation

Testing verifies system behavior.

Evaluation measures AI output quality.

## Golden Dataset

A curated collection of representative inputs
and expected behavior.

## Exact Match

Useful for deterministic outputs but weak for
natural-language answers.

## Semantic Similarity

Measures whether two answers have similar meaning.

This project includes a simple cosine similarity
baseline.

Production systems can use embeddings for stronger
semantic evaluation.

## Correctness

Measures whether the answer is factually correct.

## Relevance

Measures whether the answer addresses the question.

## Faithfulness

Measures whether an answer is supported by the
provided context.

## Hallucination

A hallucination is unsupported or false information
generated by the model.

## RAG Evaluation

Retrieval:

- precision
- recall
- hit rate
- MRR

Generation:

- correctness
- relevance
- faithfulness

## LLM-as-a-Judge

Question

- Expected Answer
- Actual Answer
- Context
  ↓
  Judge LLM
  ↓
  Evaluation Scores

LLM judges are not perfect.

They should be validated using human evaluation
and other automated signals.

## Weighted Evaluation

Correctness = 40%

Relevance = 30%

Faithfulness = 30%

Overall:

correctness \* 0.4

- relevance \* 0.3
- faithfulness \* 0.3

## Regression

Prompt/model change
↓
Run regression dataset
↓
Compare evaluation
↓
Detect quality regression

## Versioning

Track:

- model version
- prompt version
- dataset version
- evaluator version

## Production Feedback

Production failure
↓
Investigate
↓
Create evaluation case
↓
Add to regression dataset
↓
Protect against future regression

## Agent Evaluation

Evaluate:

- task completion
- tool selection
- tool arguments
- iterations
- latency
- cost
- final answer

## Operational Metrics

Evaluate:

- quality
- latency
- cost
- token usage

## Core Principle

A GenAI application is not complete merely because
it produces an answer.

It must be measurable.

If you cannot measure AI quality,
you cannot reliably improve AI quality.
